# docs/legacy/

Historical artifacts that are no longer load-bearing for the project but kept for reference.

## web-prototype/

The original static HTML + in-browser-Babel JSX prototype for mqdir.com (the marketing landing page and the interactive prototype demo). This was the canonical source for the live mqdir.com from project inception through 2026-05.

**Current status (2026-05):** mqdir.com is now served by a separate **private** Next.js + MDX companion repository (deployed independently to Vercel) that hosts both the marketing landing and the SEO/AEO/GEO blog system. This `web-prototype/` directory is preserved here as a historical snapshot of the original design language and theme tokens, not as the source of truth for the live site.

If you need to reconcile a visual regression, compare against the live mqdir.com (or the private companion repo) — not this snapshot. The colors, density, and layout in the live site have evolved beyond what's captured here.
